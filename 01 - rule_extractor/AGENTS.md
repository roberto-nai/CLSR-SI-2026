# Project conventions

Use British English throughout all code supplied for this project, including comments, docstrings, identifiers, command-line messages, generated field names, prompts and documentation.

Preserve exact external API parameter names, third-party interfaces, verbatim source quotations, bibliographic titles and user-supplied filesystem paths when their original spelling is required.

DECLARE activity arguments must exactly match the selected event log's Activity values. Preserve each label's original spelling, capitalisation, spacing and punctuation; never translate or replace it with a synonym or snake_case variant.
